MY WORK

  • This is my current capstone game, Red Flame and Fable! It’s a 2D action platformer made in Unity with a team of 13 and over 2 semesters. Heavily inspired by games like Darkwood and Holo Knight, I tapped into Unity’s lighting system in order to create dynamic vision that unrenders enemies not in LOS of the player. Also, for this project, I was responsible for the flower and lantern system and the enemy and boss AI.

    Red Flame And Fable

  • Touhou99 is a networked bullet-hell game inspired by Touhou and Tetris-99. This Game was created by a team of 3 people using Unity and Steam Game Networking sockets. For this game, I created a tool for the rest of the team to easily create enemy wave patterns and custom bullet attacks. So grab a friend and click the link below to give it a try!

    Touhou99

  • Bisque Bash is a two-player physics puzzle game where two Claylings have to escape the kiln before they get refired! Bisque Bash was created for the Ubisoft Game Labs Competition in 2025 and was a runner-up for best art direction. For this project, I worked with an interdisciplinary team of 8 people, where I was responsible for networking and physics systems. This was accomplished using a mix of the Unreal networking subsystem and custom C++ code. This game was also cross-compiled for Linux, so it could be hosted on an AWS EC2 for a streamlined judging experience.

    Bisque Bash

  • I am an avid player of D&D, so while exploring the world of assembly and microcontrollers, I wanted to create something I could use. So I created an RNG dice roller using an AVR and an Arduino to control an LED panel to show the number. I also created a research paper on my experiment using Overleaf and LATEX.
